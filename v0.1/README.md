# Property Analyzer V0.1

一个供个人研究使用的房地产投资分析器。HTML + CSS + 普通 JavaScript；无后端、账户、数据库、安装步骤或第三方运行依赖。基础计算完全离线。

## Windows 上运行

1. 下载 `Property-Analyzer-V0.1.zip`，右键选择“全部解压缩”。不要在压缩包内直接打开程序。
2. 打开解压后的 `Property-Analyzer-V0.1` 文件夹，双击 `index.html`。
3. 推荐使用最新版本的 Microsoft Edge 或 Google Chrome。如文件打开在其他软件中，右键 →“打开方式”→ 选择浏览器。
4. 页面打开后即可使用；无需联网，也不需要运行命令或启动服务器。

请将 HTML、CSS 和 JS 文件保留在同一个文件夹。首次打开自动加载三套虚构示例。

## 怎么使用

- **编辑房产**：点击房产卡片或左侧名称，在“房产详情与测算”中修改输入。数据变化后自动重算，并显示公式与费用明细。
- **新增或复制**：点击“添加房产”或“复制房产”。城市可任意填写；计算不依赖城市预设。支持三套以上同时比较。
- **金额单位**：每套房产的价格、租金和费用都使用该房产的币种。购入税费填一次性金额；物业管理费、房产税、保险维修、出租托管费均填**全年固定金额**。零费用请填 `0`。
- **切换原币**：仅改变输入金额的币种标签，不自动换算原始输入；请同步更新金额。
- **横向比较**：默认 USD，可切换 EUR、SGD、AED。手动汇率始终填写“1 单位原币 = 多少 USD”；USD 固定为 1。无需自行填写交叉汇率。
- **压力测试**：勾选租金下降 10%、空置增加 2 个月、市场价值下降 20%，可以组合；影响全部房产的当前情景。点击“恢复基础”清除情景。
- **保存与恢复**：浏览器允许时自动保存到本机。使用“导出数据”下载 JSON 备份；“导入数据”恢复或替换当前数据。未完成的输入也可导出、导入，并继续编辑。
- **恢复演示**：导入同文件夹内的 `demo-data.json`；这会在确认后替换当前数据。

本机自动保存依赖浏览器对本地 HTML 文件存储的支持。更换浏览器、移动文件、清除浏览器数据或使用隐私模式，可能无法保留数据；**JSON 导出文件是可迁移的备份**。自动保存失败会显示提示，计算仍可正常使用。导入失败不会覆盖当前数据。

## 计算口径

设购买价格为 P、一次性购入税费为 A、情景月租金为 R、年度空置月数为 V、四项年度固定费用之和为 E、所得税率为 t（例如 20% = 0.20）。

| 指标 | 公式 |
| --- | --- |
| 购入总成本 / Total Acquisition Cost | P + A |
| 年度理论毛租金 / Annual Gross Rental Income | R × 12 |
| 有效租金 / Effective Rental Income | R × (12 − V) |
| 毛租金回报率 / Gross Rental Yield | 理论毛租金 ÷ P × 100% |
| 年度运营成本 / Annual Operating Expenses | 物业管理费 + 年度房产税 + 保险维修费 + 出租托管费 |
| 年度税前净租金 / Net Rental Income Before Tax | 有效租金 − E |
| 税前净回报率 / Net Rental Yield | 税前净租金 ÷ (P + A) × 100% |
| 简化税后净收入 / Estimated After-tax Income | 税前净租金 − max(税前净租金, 0) × t |

空置损失 = R × V；空置损失和租金所得税不重复计入年度运营成本。亏损时不假设税收抵免。

压力情景使用原始输入独立计算，不会多次叠加：R = 原月租金 × 0.90；V = min(12, 原空置月数 + 2)。未勾选的项目保持基础值。市场估值默认为 P，勾选下跌后为 P × 0.80，**原始购买价格、购入总成本及当年租金现金流均不因市值下跌而改变**。

首年总回报金额 = 税后净收入 + 年末市场估值 − 购入总成本；总回报率 = 总回报金额 ÷ 购入总成本 × 100%。这包含一次性购入税费及未实现的估值变化，因此基础情景首年总回报率可能低于租金回报率、甚至为负。

统一货币金额 = 原币金额 × 原币对 USD 汇率 ÷ 目标币对 USD 汇率。回报率保持原币计算结果，不受仅用于比较的汇率影响。

价格及面积必须大于 0；租金和费用不得为负；空置月份允许 0–12（含小数）；税率允许 0–100%；汇率必须为有效正数。缺失、非法输入或溢出会提示修正，不会显示旧测算结果。金额展示至小数点后两位，计算过程中不提前取整。

这是简化的全现金、全年持有模型。未建模贷款、折旧、出售费用和资本利得税。税率完全由用户输入，不代表当地实际税制；各城市的市场价格、租金、费用和税率均未写入计算逻辑。

## 演示数据

三套示例分别为迪拜“海湾花园公寓”、巴塞罗那“阳光街住宅”、新加坡“绿岸公寓”。物业、价格、面积、租金、费用、税率及初始汇率**全部为虚构演示数据，不是实时市场数据，也不是税务建议**。示例可以自由编辑；新增房产不会继承城市特定规则。

## 运行测试

**无需安装软件的方式**：双击 `tests.html`，或在程序底部点击“运行计算测试”。页面会自动执行测试，并支持重新运行。预期为 **53 项通过、0 项失败**。

测试覆盖八项核心公式、不同回报率分母、一次性费用、负收入税额、全年空置、小数空置、三种压力情景及组合、输入不被修改、跨币种换算、输入校验与数值溢出。

可以手动核对以下独立测试数据（同一原币）：房价 200,000，购入税费 10,000，月租金 1,500，空置 1 月，四项费用分别为 1,200、900、600、1,200，所得税率 20%。预期总成本 210,000；毛租金 18,000；有效租金 16,500；费用 3,900；税前净租金 12,600；毛回报率 9%；税前净回报率 6%；税额 2,520；税后净收入 10,080。仅勾选市场价值下降：估值变为 160,000，其余上述租金与成本结果保持原值；首年总回报金额为 −39,920。

**开发者可选方式**：已安装 Node.js 时，在程序文件夹中运行 `node tests.js`。普通使用者不需要安装 Node.js。`browser-tests.cjs` 是额外的浏览器流程测试，需开发环境中的 Playwright，不影响程序或 `tests.html` 使用。

开发验证使用 Linux Chromium，53 项计算测试及 21 项浏览器流程检查全部通过，包括备份恢复、压力情景、无效输入、窄屏布局和无 JavaScript 异常；另外通过了断网、零资源请求的源码运行检查。该受管开发浏览器禁止 `file://` 导航，因此完整界面流程通过临时 localhost 静态服务验证；这不是程序运行依赖。交付程序使用普通本地脚本和样式，没有模块、fetch、CDN 或服务器 API；Windows 用户按上方双击说明运行，并可用 `tests.html` 自检。
